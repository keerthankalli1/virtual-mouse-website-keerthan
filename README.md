# Virtual Mouse Website

A responsive, static project website for the Virtual Mouse hand gesture recognition system.

## Preview locally
1. Extract the ZIP.
2. Open the `virtual_mouse_website` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Edit `index.html`, `style.css`, and `script.js` to customize the site.

## Publish later with GitHub Pages
Create a GitHub repository, upload these three website files (and this README if desired), then enable Pages in the repository's Settings. For a student project, check whether your repository should be public before publishing.

## Before submitting
- Add your name, college, guide, screenshots, and project links if required.
- Verify the technologies and gestures against the final application.
- Add only performance measurements that you have actually tested.
- This is a static informational website; it does not control the desktop mouse from the browser.
